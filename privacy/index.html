Montclar · BreachLedger

Privacy Policy

Effective date: September 24, 2026

BreachLedger is a Zendesk app published by Montclar. This policy explains what information BreachLedger accesses and how it is handled.

Data BreachLedger accesses

To reconstruct historical ownership at a first-response SLA breach, BreachLedger reads Zendesk ticket metric events, ticket audit history, ticket assignment and group information, ticket status, and the names associated with relevant Zendesk users and groups.

How the data is used

The data is used only to identify the historical assignee, group, and status at the breach timestamp, show supporting evidence, and allow an authorized user to export an evidence JSON file.

Storage and retention

The current BreachLedger app processes Zendesk data in the app session. Montclar does not operate a separate BreachLedger backend that receives or stores ticket content, metric events, audit history, or user/group data. If a user downloads an evidence JSON file, that file is stored wherever the user chooses to save it and remains under that user's control.

Sharing

Montclar does not sell BreachLedger customer data and does not share Zendesk ticket data with advertisers or unrelated third parties. The app communicates with Zendesk through the Zendesk App Framework and Zendesk APIs required for its functionality.

Security and access

BreachLedger is designed for authorized Zendesk administrators. Access remains subject to the permissions and security controls of the customer's Zendesk account.

Changes to this policy

If BreachLedger's data practices materially change, this policy will be updated before those changes are released.

Contact

Questions about privacy or BreachLedger can be sent to samuel@montclar.app.
